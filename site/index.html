Nacho Viewer

Markdown, beautifully printed.

A free, open-source document viewer for Linux, Windows and macOS that makes .md files read like a well-typeset document instead of plain text.

Windows macOS Linux

Every file is on GitHub Releases.

What it does

  • A paper-sheet reading view with book-quality typography, light and dark
  • Everything GitHub renders (tables, footnotes, alerts, emoji, math, Mermaid) plus a few extras
  • Tabs, an outline, live reload when the file changes, zoom, and export to PDF
  • It stays a viewer: it never changes your files
