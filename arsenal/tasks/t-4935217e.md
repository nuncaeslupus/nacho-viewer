**Severity:** medium · **Confidence:** medium · **Category:** security

**Where:** `src/render/enhance/svg.ts:31-35, src/render/enhance/svg.ts:46-54, src/render/sanitize.ts:19, src/app.css:322`

### Finding
sanitizeSvg drops <style> but keeps style="..." unless it contains an external url()/backslash. An SVG beside an untrusted document with style="position:fixed;inset:0;z-index:99999" is inlined into the live DOM and can cover the whole window, including the custom-drawn title bar/close button (decorations:false) and the menus, to spoof UI or trap the user. Raw HTML in Markdown can do a weaker version by borrowing app classes (class is allow-listed; e.g. class="file-menu" is position:fixed).

### Evidence
Traced the hook: for name==='style' with no url( the attribute is re-set unchanged; DOMPurify's svg profile allows style. app.css has no contain/transform on the sheet that would trap fixed positioning (grep 'contain' finds none). Not run in a browser.

### Suggested direction
Strip position/z-index (or all style) from inlined SVG roots and wrap them in a container with contain: paint/layout; namespace app chrome classes or strip non-allow-listed classes from document HTML.
