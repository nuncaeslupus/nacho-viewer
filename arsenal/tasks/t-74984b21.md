### Finding
The Windows and macOS CI jobs filter Rust tests to names containing 'export'. test_resolve_gives_plain_paths_the_page_can_join exists specifically for the Windows \\?\ prefix, and the scope/image-protocol tests guard path traversal, yet none execute on the platforms whose path semantics differ. The frontend e2e runs against a fake backend in a Playwright image, so real-webview IPC/CSP behaviour on those OSes is covered only by an 'alive after 10 s' smoke.

### Evidence
grep of ci.yml: the only cargo test invocations in the windows-latest and macos-latest jobs are `cargo test export`.

### Suggested direction
Run the full `cargo test` on all three OSes (they are fast unit tests) and add Windows-path cases to the TS link tests.
