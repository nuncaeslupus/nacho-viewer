### Finding
Config.remote_images defaults to true and the base CSP allows img-src https:. Opening an untrusted .md (the stated use: downloaded READMEs, notes) fetches every remote image immediately, leaking IP/time-of-open to the author (tracking pixel) with no prompt; Flatpak/Snap are granted network for exactly this.

### Evidence
Read Config::default and shell fallback (`?? true`); imagePolicy keeps remote src when remoteImages is true.

### Suggested direction
Default to off with a per-document 'load remote images' notice (the data-remote-src placeholder already exists), or at least document the default prominently.
