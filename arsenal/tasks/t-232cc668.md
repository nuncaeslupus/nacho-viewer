### Finding
Scope::allow inserts the file's parent folder and in_folders matches any ancestor, so opening ~/notes.md (or a file dropped from /) lets the webview read every .md, image and .svg under the whole home tree; the grant is never revoked on tab close and the 10 recent files re-grant their folders at every launch. Any renderer-side bug (sanitizer bypass) therefore reads far more than 'the document and its siblings'.

### Evidence
Traced allow()/in_folders(); test_read_document_outside_scope_not_permitted confirms sub/deep.md is readable. Design choice, but the blast radius depends on where the first file happened to live.

### Suggested direction
Cap depth or refuse to scope very broad roots (home, /, drive root) beyond the file itself; grant folders lazily when a link/image is actually followed; drop grants when the last tab of a folder closes.
